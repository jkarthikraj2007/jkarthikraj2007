## 🚀 Featured Projects

### 🔍 PixelProof: Image Tampering Detection (Real vs Edited)
An image forensics app that helps tell whether a picture is **authentic or has been edited**. Upload an image and PixelProof analyses it using image-processing techniques to flag possible tampering.

**Focus areas:** Image Processing · Image Forensics · Web App

---

### ✈️ Flight Price Predictor
An ML app that predicts domestic flight fares in India, built end to end and deployed with a clean UI.

- Trained on a Kaggle Indian domestic flights dataset
- Moved from Random Forest to **GradientBoostingRegressor** to fit cloud memory limits
- 🔗 [Live demo](https://flight-price-predictor-kig.streamlit.app)

**Stack:** Python · Pandas · scikit-learn · Streamlit

---

### 🔐 ConfidentialVault
A Hardhat-based Solidity project using **Fhenix / CoFHE fully homomorphic encryption**, so contract data can be computed on while it stays encrypted.

**Stack:** Solidity · Hardhat · Fhenix (FHE)

---

### ♻️ Kabadiwala App
A mobile app for scrap collectors: photograph scrap, get an AI material classification and estimated value, find nearby recyclers and track transactions.

- Offline-first, with local saving and automatic sync when connectivity returns
- Built for low-literacy users with Hindi/Marathi and audio/pictorial UI
- I own the **Flutter frontend** and UI/UX in a team project

**Stack:** Flutter · Dart · SQLite/Hive · REST APIs

---

### 🌾 Earthworm: AI AgriTech Assistant *(concept / MVP planning)*
A farming assistant concept covering crop suggestion by soil type, harvest time prediction and market price forecasting.
