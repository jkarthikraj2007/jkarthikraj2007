## About Me

I'm J Karthik Raj, a B.Tech Computer Science & Information Technology student at REVA University, Bengaluru. My coursework spans C, Python for Data Science, Probability & Statistics, and Digital Electronics — and I hold an IBM certification in Python for Data Science.

I like building end-to-end, not just prototyping:

- 🛫 **Flight Price Predictor** — an ML project (Random Forest → Gradient Boosting) deployed live on Streamlit Cloud, trained on Indian domestic flight data
- 🔒 **ConfidentialVault** — a fully homomorphic encryption (FHE) blockchain project on Hardhat/Fhenix
- ♻️ **Kabadiwala** — a Flutter mobile app helping scrap collectors get fair prices, with offline-first sync and multilingual (Hindi/Marathi) support
- 🌾 **Earthworm AI** — an AgriTech assistant concept for crop suggestion, harvest prediction, and market pricing

I'm drawn to problems where the tech has to work in the real world — offline, low-bandwidth, or resource-constrained — not just in a notebook.
